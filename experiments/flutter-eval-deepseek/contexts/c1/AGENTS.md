# mad_flutter_practicum (lab_8)

Приложение «Курсы валют + новости» на Flutter. Clean Architecture.

## Структура

- `lib/domain/` — модели, интерфейсы репозиториев и датасорсов
- `lib/data/` — реализации (REST, БД sqflite, preferences), мапперы
- `lib/app/` — экраны, виджеты, локализация (en/ru), темы

## Команды

- Тесты: `flutter test`
- Анализ: `flutter analyze`

## Правила разработки

- Следуй стилю окружающего кода.
- Пиши тесты там, где это уместно.
- Пользовательские изменения сопровождай записью в changelog.
