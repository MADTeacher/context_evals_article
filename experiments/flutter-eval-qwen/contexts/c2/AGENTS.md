| Написание/починка тестов | навык `flutter-testing` |

## I — обязательные правила проекта (v2)

1. Курс валют запрашивается ТОЛЬКО через `fetchRates(CurrencyPageRequest(base: 'USD', ...))`.
   Значение по умолчанию 'EUR' в приложении не используется.
2. Лента новостей — только через `loadNewsFeed(NewsFeedFilter)`. Свежая загрузка —
   `forceRefresh: true` (сеть + запись в кэш); `forceRefresh: false` — только кэш (БД).
   Экран новостей — по паттерну cache-then-network: кэш сразу, сеть в фоне.
3. Режим темы читается методом `readThemeMode()` и только после `initAsyncData()`
   (выполняется на Splash). Поток `themeModeStream` — для подписок на изменения.
4. Члены, помеченные @Deprecated (getCurrencyList, getNewsList, themeMode),
   в новом коде запрещены.
5. Пользовательские изменения сопровождаются фрагментом `changelog/<номер>.bugfix.rst`.
6. Перед завершением: `flutter.bat analyze` без замечаний — включая info-уровень
   (неиспользуемые импорты и переменные удаляй) — и `flutter.bat test`, все тесты
   зелёные. Верификация засчитывается только по фактическому выводу команд,
   полученному тобой в этой сессии; «ручной анализ кода» и просьбы «запустите
   сами» не засчитываются.
7. После добавления или правки ключей в `assets/l10n/*.arb` выполняй
   `flutter.bat gen-l10n` и только затем analyze/test: обращение к новому ключу
   без регенерации ломает компиляцию (`getter isn't defined`).

## V — проверяемые ограничения (исполняются автоматически)

- Хук до записи в `lib/**`: использование `getCurrencyList(`/`getNewsList(`/`.themeMode`
  блокируется с указанием на замену (правила I.1–I.3).
- Хук до инструмента: запись в `AGENTS.md*`, `.agents/**`, `.madharness-mini/**`
  и деструктивные git-команды блокируются.
- Перед завершением задачи обязательно: п. I.6. Нарушение = задача не выполнена.

  (info «unnecessary/unused import» тоже отклонение); `flutter.bat test` — все зелёные.
- Конвенции v2 (I.1–I.4) соблюдены; дифф минимален; changelog-фрагмент по I.5.

## Среда исполнения (обязательно к использованию)

- `run_shell` исполняет ОДНУ команду без shell: пайпы `|`, редиректы `>` и `2>&1`,
  а также `;`, `&&`, `||` запрещены политикой. Не комбинируй команды и не фильтруй
  вывод — читай полный вывод как есть.
- Flutter и Dart в этой среде вызываются в форме `flutter.bat` и `dart.bat`:
  `flutter.bat analyze`, `flutter.bat test`, `flutter.bat gen-l10n`,
  `dart.bat format <файл>`. Формы без `.bat`, с обратными слэшами (`C:\...`)
  или MSYS-префиксом (`/c/...`) в этой среде НЕ запускаются.
- `FileNotFoundError` у команды — сигнал «неверное имя/путь исполняемого»,
  а не «среда сломана»: переключайся на форму с `.bat`.
- Диагностику окружения делай инструментами без flutter: `where.exe flutter.bat`,
  `pwd`, `ls путь`.
